# Библиотечная информационная система

Учебный сайт по предоставленному PDF. PHP 8.0+, PDO, mbstring; SQLite для локальной проверки, схема MySQL 8 / MariaDB 10.6 для хостинга. Без Composer, сборки и внешних CDN.

## Возможности

- Гость: каталог, быстрый и расширенный поиск, регистрация и вход.
- Читатель: заявка на свободную книгу, отмена своей заявки, активные и возвращенные книги, состояние заявки, даты и счетчик просрочек.
- Администратор: все возможности читателя; добавление, изменение и удаление книг без истории; обработка заявок, выдача на 14 дней, продление на 1–90 дней, прием возврата; статистика и управление читателями.
- По PDF одна карточка — один выдаваемый экземпляр. Несколько читателей могут подать заявки; выдача одному не допускает повторную выдачу другим до возврата.

## Быстрый запуск Windows

1. Установите PHP 8.0+ с `pdo_sqlite` и `mbstring` (подходит XAMPP).
2. Запустите `run.ps1` из папки проекта. Для чистой базы скрипт запросит новый пароль администратора (от 12 символов).
3. Откройте http://127.0.0.1:8086. Email администратора по умолчанию: `admin@library.test`.

Если политика PowerShell запрещает скрипт, выполните в терминале:

```powershell
$env:ADMIN_PASSWORD='ЗАДАЙТЕ_СВОЙ_ПАРОЛЬ_ОТ_12_СИМВОЛОВ'
php bin/install.php
Remove-Item Env:ADMIN_PASSWORD
php -S 127.0.0.1:8086 -t public
```

Для учебных выдач и трех читателей при первой установке задайте также `READER_PASSWORD` и выполните `php bin/install.php --demo`. Флаг предназначен для пустой базы. Пароль не сохраняется в коде: в БД хранится хеш. Имеющаяся локальная демонстрационная база и файл с доступами поставляются отдельно и не входят в публичный архив исходников.

## Структура

`public/index.php` — страницы с HTML, `public/assets` — CSS и JavaScript, `app/bootstrap.php` — подключение БД и общие функции, `app/actions.php` — серверные операции, `database` — две схемы, `bin/install.php` — установка из командной строки, `storage` — данные вне публичного каталога, `docs` — диаграммы и инструкции.

## Размещение

См. `docs/DEPLOY.md`. Предпочтительно назначить корнем сайта папку `public`. На Apache с доступным `mod_rewrite` можно разместить весь проект в корне сайта: приложенный `.htaccess` запрещает доступ к служебным папкам. Проверьте 403 для `/storage/library.sqlite` и `/app/config.local.php`. На Nginx нужно настроить корень на `public`; `.htaccess` там не применяется.

## Дизайн и публикация

Ссылки на внешние результаты и их фактический статус записаны в `docs/LINKS.md`. Публичный GitHub хранит только исходники, диаграммы, изображения интерфейсов и исходный архив. Не загружайте туда локальную БД, пароли и заполненный отчет с учетными данными.

## Проверки

Проверены PHP 8.0.30 / SQLite: 26 интеграционных сценариев; ширины браузера 320, 390, 768, 1360 px. MySQL-схема подготовлена, но на сервере MySQL пока не исполнялась. Защита: PDO prepared statements, экранирование HTML, CSRF, серверная проверка роли, password_hash/password_verify, смена ID сессии, HttpOnly и SameSite. Ограничение попыток входа действует внутри одной сессии; для открытой эксплуатации добавьте ограничение по IP на веб-сервере и HTTPS.
